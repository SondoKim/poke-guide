# 포켓몬 GO 실전 개체 분류 가이드 (PKGO IVGD)

블룸버그 터미널 스타일의 포켓몬 GO 개체 분류 가이드. 단일 HTML 파일 — 외부 의존성 없음.

- **라이브 페이지**: https://sondokim.github.io/poke-guide/
- 분류: 1) 레이드+배틀리그 겸용 / 2) 레이드 전용 / 3) 배틀리그 전용 / 4) 도감작 후 박사행
- 순위 출처: PvPoke 종합 랭킹 (GL/UL/ML), Dittobase 타입별 레이드 딜러 랭킹, PvPoke gamemaster의 특별한 기술머신(레거시) 목록
- 기준일: 2026-09-15

## 사용법
`index.html`(= `poke_guide.html`)을 브라우저로 열면 끝. 검색창(`/` 키), 숫자키 1~5로 섹션 이동.
